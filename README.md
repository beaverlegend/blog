Kerry’s Minecraft Blog (2019 Summer Project)

Welcome to the little Minecraft blog I built about five years ago. This was a summer experiment where I learned basic web dev by writing about Minecraft builds, mob farms, and random ideas I was into back then. It’s simple, it’s nostalgic, and I’m keeping it here as a snapshot of where I started.

What’s Inside

A basic HTML/CSS site

Short blog posts about Minecraft things I was learning or building

Old screenshots and notes from my worlds

Beginner-level code that shows how I started getting into web projects

Why I Made It

Back in the summer of 2019, I wanted something fun to work on that wasn’t school or robotics. This blog was just me messing around, teaching myself how to structure pages, write posts, and style things. Nothing fancy, just learning by doing.

How to View It

Download or clone the repo

Open index.html in any browser

That’s it

If You Want to Use or Build On It

This project is super lightweight. Feel free to:

Re-theme the layout

Add new posts

Turn it into a more polished site

Use it as an example of early web dev work

Notes

This blog isn’t maintained anymore. I’m just keeping it here as a fun archive of where my coding journey started.
